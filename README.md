# praktika-kit

Одностраничный лендинг комплекта «Практика ИИ-маркетинга · Издание 2.0».

- index.html — сама страница (все стили внутри файла, внешних зависимостей нет)
- .nojekyll — отключает обработку Jekyll на GitHub Pages, чтобы файл отдавался как есть

## Обновление

Заменить index.html в репозитории. Cloudflare Pages пересоберёт страницу автоматически.

## Плейсхолдеры в файле

- PAYMENT_LINK — ссылка на оплату полного комплекта (4 900 ₽)
- PAYMENT_LINK_PDF — ссылка на оплату PDF-версии (2 900 ₽)
- OFFER_LINK — адрес опубликованной оферты
